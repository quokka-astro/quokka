# ChuhanProblem Metallicity Visualization Guide

After running ChuhanProblem tests, automatically visualize the chemical scalar fields (C12, N14, O16) using yt.

## Quick Start

### 1. Run the Test
```bash
cd /Users/meow/quokka
ctest --test-dir build-chuhan -R ChuhanProblem
```

### 2. Generate Metallicity Plots

**Option A: Automatic (via CMake)**
```bash
cmake --build build-chuhan --target ChuhanProblem_plots
```
This will:
- Find all `plt*/` directories generated by the test
- Generate 9 slice plots (3 fields × 3 timesteps)
- Save to `tests/chuhan_metallicity_plots/`

**Option B: Manual (with custom paths)**
```bash
python3 scripts/python/plot_chuhan_metallicity.py tests/plt0000000 tests/plt0000005 tests/plt0000010 \
  -o tests/chuhan_metallicity_plots -j 4
```

## What You Get

For each timestep and chemical field:
- **scalar_0** (C12) – Carbon-12 abundance
  - Visualized with `viridis` colormap
- **scalar_1** (N14) – Nitrogen-14 abundance
  - Visualized with `plasma` colormap
- **scalar_2** (O16) – Oxygen-16 abundance
  - Visualized with `cool` colormap

Output files (example):
```
tests/chuhan_metallicity_plots/
├── scalar_0_ts0000000_Slice_z_scalar_0.png    # C12 at t=0
├── scalar_0_ts0000005_Slice_z_scalar_0.png    # C12 at t=5

├── scalar_1_ts0000000_Slice_z_scalar_1.png    # N14 at t=0
├── scalar_1_ts0000005_Slice_z_scalar_1.png    # N14 at t=5
├── scalar_1_ts0000010_Slice_z_scalar_1.png    # N14 at t=10
├── scalar_2_ts0000000_Slice_z_scalar_2.png    # O16 at t=0
```

## Features

- **Z-axis cross-sections** – Slice plots perpendicular to z-axis
- **AMR grid overlay** – Semi-transparent grid lines showing refinement structure
- **Particle annotations** – Stellar particles marked with asterisks (if plotting code is extended)
- **Multiple colormaps** – Each field uses distinct, publication-quality colormap
- **Parallel processing** – up to 4 simultaneous plot generations (via `-j` flag)
- **Auto-scaling** – Color limits automatically adjusted per field and timestep

## Script Details

**Location**: `scripts/python/plot_chuhan_metallicity.py`

**Command-line options**:
```bash
python3 scripts/python/plot_chuhan_metallicity.py <plotfiles> [options]

Options:
  -o, --output DIR        Output directory for PNGs (default: figures)
  -j, --n_processes N     Parallel workers (default: 1)
```

## Integration with Test Suite

The CMake target `ChuhanProblem_plots` is automatically registered when:
1. `AMReX_SPACEDIM=3` is enabled
2. `src/problems/ChuhanProblem/CMakeLists.txt` is read

To regenerate plots after test reruns:
```bash
cmake --build build-chuhan --target ChuhanProblem_plots
```

This target:
- Depends on `ChuhanProblem` executable (rebuilds if needed)
- Uses `python3` from current environment
- Respects the script's error handling (non-blocking failures)
