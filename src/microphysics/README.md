# Microphysics

Parts of Quokka's chemistry and photochemistry code, and its equations of state `EOSIdeal` and `EOSMultigamma` with their floors (`src/hydro/EOS.hpp`, `src/hydro/EOSFloors.*`), are adapted from [AMReX-Astrophysics Microphysics](https://github.com/AMReX-Astrophysics/Microphysics), written by the Microphysics development team. They were taken from the fork <https://github.com/chongchonghe/Microphysics-fork>, branch `james471/primordial-chem-no-using-namespace-amrex`, at commit `eba42a12`.

That code is covered by Microphysics' BSD 3-clause licence, in [`LICENSE`](LICENSE).
